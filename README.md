# Xiaomi Camera vendor files for flourite

Camera 6.7.000070.0 adapted by `device/xiaomi/flourite-miuicamera`, with native
libraries from flourite OS3.0.306.0.WPRMIXM. Place this repository at
`vendor/xiaomi/flourite-miuicamera`.

The APK is split into three parts for repository storage. Soong joins them in
numerical order without changing the APK. The complete APK SHA-256 is
`d661771a3931f45bf470a76ed94050f30889f3272c698ef9a7900fca28b639d6`.

To regenerate the files, follow the extraction instructions in the device
camera repository. Extraction produces a complete APK; the split representation
is only needed when publishing this repository.
